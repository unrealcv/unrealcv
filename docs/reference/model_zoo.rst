UnrealZoo
=========

The UnrealCV Model Zoo has moved to `UnrealZoo <https://unrealzoo.github.io/>`_.
UnrealZoo provides the maintained Unreal environments and pre-built binaries
for use with UnrealCV.

   :alt: UnrealZoo collected scenes, playable entities, and embodied AI agents
   :target: https://unrealzoo.github.io/
   :width: 100%
   :align: center

Open the `UnrealZoo website <https://unrealzoo.github.io/>`_ to explore the
available environments and agents.
